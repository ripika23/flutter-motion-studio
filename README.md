✨ Motion Studio

Bring your UI to life.

A modern and visually immersive Flutter animation showcase built to demonstrate the power of Flutter's animation framework.

Motion Studio combines smooth transitions, interactive components, animated transformations, glowing visual effects, and responsive layouts into a single premium interface.

🚀 Overview

Motion Studio is a Flutter UI experiment focused on creating smooth, expressive, and interactive animations using Flutter's built-in animation capabilities.

The project is designed to demonstrate how animation can transform an ordinary interface into an engaging user experience.

✨ Features
🎬 Smooth entrance animations
🌊 Fade and slide transitions
🔍 Scale animations
🔄 Continuous rotation animations
✨ Animated glowing orb
🧩 Interactive animated components
🔀 AnimatedSwitcher transitions
🎨 AnimatedContainer effects
🖱️ Desktop/Web hover animations
📱 Responsive mobile layout
🌌 Modern dark glassmorphism UI
💜 Neon gradient visual effects
⚡ Smooth animation curves
🎛️ Play/Pause animation control
📦 No third-party animation packages required
🎨 Animation Technologies

This project demonstrates several core Flutter animation APIs:

Animation	Flutter API
Fade	FadeTransition
Slide	SlideTransition
Scale	ScaleTransition
Custom animation	AnimationController
Custom rendering	AnimatedBuilder
Size & color changes	AnimatedContainer
Content transitions	AnimatedSwitcher
Rotation	Transform.rotate
Movement	Transform.translate
Timing	Tween
Motion curves	CurvedAnimation

🚀 Getting Started
Prerequisites

Make sure you have Flutter installed on your computer.

You can verify your Flutter installation with:

flutter --version

Clone the repository
git clone https://github.com/ripika23/flutter-motion-studio.git

Enter the project
cd flutter-motion-studio

Install dependencies
flutter pub get

Run the application
flutter run


You can also run the project on a connected Android/iOS device, emulator, or supported Flutter desktop/web target.

🎮 Interactions

Motion Studio includes interactive elements designed to demonstrate animation in action.

▶️ Animation Control

Use the play/pause button to control the continuous animations.

✨ Interactive Card

Hover over the animation cards on supported desktop/web platforms to see their elevation and glow effects.

💫 Motion Component

Tap the interactive component to trigger an animated transformation using AnimatedContainer and AnimatedSwitcher.
